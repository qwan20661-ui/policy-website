# 企业政策匹配流程

## 整体流程（六步）

| 步骤             | 做什么                                 | 关键规则 |
| ---------------- | -------------------------------------- | -------- |
| ① 给企业画像     | 把工商数据整理成标准标签和指标         | 数据缺失记"未知" |
| ② 选出候选政策   | 从政策库先挑出一批相关政策             | 规则命中 + 标签检索 |
| ③ 申报要求判定   | 先核对硬性条件，硬性通过再核对软性条件 | 硬性一票否决 |
| ④ 算分           | 硬性、软性条件一起算 0–100 符合度      | 100 / 30 起步 / 10 |
| 业务规则再过滤 | 去掉"已有资质不用再申请"等不合适的     | 5 条过滤规则 |

---

## ① 给企业画像

把工商信息整理成标签

## ② 选出候选政策

根据画像，用 **规则命中 + 标签检索** 从政策库先挑出一批候选

| 关卡 | 在做什么 |
| ---- | -------- |
| G0 前置拦截 | 企业（失信/经营异常） |
| G2 普遍通道 | 比对政策和企业的标签，两边都有数据进行比对，政策和企业都有则进入候选，1、标签维度企业规模（成立时间，营收），通用政策规模覆盖三个企业规模；2、行业领域（高企八大领域（通用政策C9需要可以推送全部企业----只能放到硬性进行筛选），通用，未来产业，数字经济）；通用规则（梯度培育、行业专项、属地政策、普惠补助、金融支持），把够得着的一批政策收进候选池------需要标签：3.研发投入，有专利的就需要把有研发要求的政策加入候选（细化类别是创新投入中研发费用（定量）） |
| G3 链路通道 | 1：创新型中小企业或者科技型中小企业<br/>			2：国家高新技术企业---》（具备前项1）新型研发机构认定----》（具备前项1）未来产业骨干企业定<br/>			3：专精特新中小企业--》（具备前项后）创新联合体认定、科技小巨人企业认定，规模以上工业企业认定（行业领域为工业，判断是否有专属领域）<br/>			4：专精特新小巨人企业---》（具备前项后）制造业单项冠军企业认定（如果是制造业可以判断），独角兽企业认定，瞪羚企业认定<br/>			5：上市后备培育企业认定<br/>			6：上市企业认定 |

## ③ 申报要求判定

每条政策把申报条件分两类：

| 类型 | 是什么 | 判定 |
| ---- | ------ | ---- |
| 硬性条件 | 1.特定行业 2.发展规模3.资质门槛4.特定区域（行政区，园区）5.研发投入（专利数量为0不推送） | 一票否决（注意成长性） |
| 软性条件 | 不满足的分低一点 | 影响分数 |

硬性：

4.1.特定园区：企业必须在对应的范围内。政策要求注册地：硬性；注意1、科学城范围，2、火炬高新区范围（需要判定企业注册地具体指什么，待核实），可以根据‘厦门火炬高新区‘需要列出每个区最有可能的地址3、自贸片区范围（待核实；判定是否可以根据公司的实际地址？集群地址？是否有标准化登记系统；根据企业的办公地点是否包含象屿路，或者含自由贸易试验区厦门片区）

4.2.六个行政区：区级政策

5.1：研发投入

```
（根据研发人员（科技人员数量或核心团队占比或科技人员占比），设备，资金的投入）--判定企业有无（只针对有研发投入的）
注：可以用专利数量的判定，没有专利数量的可以不推送
```

没有的后续引导填写



判定顺序：**先硬性，后软性**。

## ④ 算分（0–100）

只有硬性全部通过的政策才进算分，硬性、软性条件都参与，全部取平均。

| 条件状态 | 得分 | 说明 |
| -------- | ---- | ---- |
| 硬性·通过 | 100 | 每条硬性记 100，一并计入平均 |
| 软性·满足 | 100 | 明确达到要求 |
| 软性·不满足 | 30 起步 | "≥"类按实际值越接近门槛越高，达不到就 30 |
| 数据缺失 | 10 | "不知道"，按低分算，不记 0 |

##  业务规则再过滤

| 规则 | 含义 |
| ---- | ---- |
| 过期政策 | 申报期截止已超两年的不推 |
| 已有资质不再申请 | 已是某资质，不推对应的"认定"政策 |
| 升级链 | 已有低级资质，只推更高一级，不推同级及以下 |
| 无专利不推研发补助 | 一条专利都没有，不推"研发补助"类 |
| 面向个人的政策 | 人才、专家、职称等面向个人申报的不推给企业 |
