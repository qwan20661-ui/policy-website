## 基线测试

执行：

```powershell
python -m pytest backend/PEMatching_v2/tests/test_policy_eligibility.py backend/PEMatching_v2/tests/test_policy_evidence.py backend/PEMatching_v2/tests/test_agent.py -q
```

结果：62 通过、3 失败。失败项为：

| 测试 | 证据 | 归类 |
|---|---|---|
| `test_冲突和不适用政策不占推荐名额` | 预期资格状态从推荐列表中排除政策 | 与 D1/D2/D5 冲突的旧原型行为 |
| `test_上游资格事实可让完整政策规则自动判为符合` | 预期资格结果改变推荐列表可见性 | 与独立资格链路边界冲突 |
| `test_多组检索覆盖单组会漏的政策` | `candidateCount=59`，断言要求大于 60 | 与资格无关的既有候选基线漂移 |

结论：当前资格原型会影响 V2 推荐行为，不能扩写或接入第五期。第五期新链路仅由调用方在推荐完成后通过 `/api/v2/eligibility/evaluate` 调用；它不写入 `recommendations`、不改 `rank`、`totalScore` 或 `band`。

## 回滚

本阶段新增文件可独立移除；未修改现有暂存原型及 V1 文件。资格 API 默认关闭，移除环境变量 `PEMATCHING_V2_ELIGIBILITY_ENABLED` 即可停止暴露新能力。
