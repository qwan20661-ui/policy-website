如果你的目标是**重新生成全部已审核主政策，并覆盖已有规则表**，使用：

```
python .\backend\PEMatching\run_generate_rule_tables.py `
  --review-status all `
  --structure-review-status all `
  --workers 20 `
  --timeout 900 `
  --sleep-seconds 1
```
|`--review-status all`|不再限定主政策审核状态为 `1`|
|`--structure-review-status all`|不限制结构化详情审核状态|
|默认 `requireSourcePolicyId=1`|仍只取主政策，不会把普通子政策混进来|
|不传 `--policy-limit`|默认 `0`，不限制总数|
|不传 `--skip-existing`|已有规则表也会重新生成并写回|
