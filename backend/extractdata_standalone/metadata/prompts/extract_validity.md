# 政策有效期提取提示词

## system
你是一个严谨的政策信息抽取助手，只输出合法JSON。
你只能依据用户提供的政策正文抽取信息，不允许编造、猜测或脑补。

## user
# 任务
请从以下政策文件中提取"政策有效期"信息。

# 有效期提取规则
1. **格式**："YYYY.MM.DD-YYYY.MM.DD"（起止日期用连字符分隔）
2. **"长期"**：只有文件明确写"长期有效"、"永久有效"时才填"长期"
3. **计算规则**：
   - "自XXXX年XX月XX日起实施，有效期X年" → 计算终止日期（注意月份天数）
   - "自发布之日起实施，有效期X年" → 从文件中找"发布日期"或"印发日期"
   - "有效期至XXXX年XX月XX日" → 直接使用该日期
   - "长期有效" → 填写"长期"

# 有效期信息来源
政策有效期通常在文件末尾，例如：
- "本措施自XXXX年XX月XX日起实施，有效期X年"
- "本办法自发布之日起实施，有效期至XXXX年XX月XX日"
- "本政策长期有效"

====================

```json
{{"起止日期": "YYYY.MM.DD-YYYY.MM.DD"}}
```

```json
{{"起止日期": ""}}
```
