## 数据来源总览

```
sys_user (主表: 用户基础信息、地址、坐标、荣誉等)
├── sys_user_company LEFT JOIN (企业信息: 信用代码、简介、联系人、科技服务领域等)
├── sys_user_provider LEFT JOIN (服务商信息: 审核状态、星级、服务分类等)
├── 子查询: xmstirx_pts.pts_server + pts_server_order → avg_star_level
├── 子查询: sys_audit_record → GROUP_CONCAT(JSON_OBJECT) → audit_records_json
└── 子查询: sys_territory_data → GROUP_CONCAT → territory_names / territory_ids
```
