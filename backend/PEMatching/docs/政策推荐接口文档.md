# 政策推荐接口文档

**版本**：V1.0  
**更新日期**：2026-07-31  
**文档状态**：正式版  

---

## 1. 接口概述

### 1.1 接口基本信息

| 项目 | 内容 |
|------|------|
| 接口名称 | 企业信息分页查询接口 |
| 接口URL | `/cms/tb-base-business-info/web/page` |
| 请求方式 | GET |
| 协议 | HTTP |
| 数据格式 | JSON |
| 字符编码 | UTF-8 |

### 1.2 服务地址

| 环境 | 地址 |
|------|------|
| 测试环境 | `http://112.48.19.225:8500` |

### 1.3 接口功能
分页查询企业完整信息，包含：
- 企业基本工商信息
- 经营信息（历年）
- 主要技术（专利）
- 主要产品
- 荣誉资质
- 投融资信息
- 国际/国家/省级榜单排名
- 知识产权统计信息

---

## 2. 请求说明

### 2.1 请求URL
```
GET http://112.48.19.225:8500/cms/tb-base-business-info/web/page
```

### 2.2 请求参数

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| pageNum | int | 否 | 1 | 当前页码，从1开始 |
| pageSize | int | 否 | 10 | 每页显示条数 |

### 2.3 请求示例
```http
GET /cms/tb-base-business-info/web/page?pageNum=1&pageSize=10 HTTP/1.1
Host: 112.48.19.225:8500
Accept: application/json
```

---

## 3. 响应数据结构

### 3.1 响应根节点

```json
{
    "code": 0,
    "msg": null,
    "data": {
        "totalCount": 1,
        "pageSize": 10,
        "totalPage": 1,
        "currPage": 1,
        "list": [...]
    }
}
```

### 3.2 响应字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| code | int | 状态码：0=成功，非0=失败 |
| msg | string | 提示信息 |
| data | object | 分页数据对象 |
| data.totalCount | int | 总记录数 |
| data.pageSize | int | 每页大小 |
| data.totalPage | int | 总页数 |
| data.currPage | int | 当前页码 |
| data.list | array | 企业数据列表 |
