1. 文档说明

1.1 文档目的

本文档用于描述政策推荐的 RESTful API 接口规范，供前端开发人员、测试人员及第三方系统集成使用。

1.2 适用范围

本接口文档适用于政策推荐中 企业信息分页查询 场景。

1.3 阅读对象

  • 前端开发工程师
  • 后端开发工程师
  • 测试工程师
  • 系统集成人员

2. 接口概述

2.1 接口基本信息

项目内容
接口名称企业信息分页查询接口
接口URL/cms/tb-base-business-info/web/page
请求方式GET
协议HTTP
数据格式JSON
字符编码UTF-8

2.2 服务地址

环境地址
测试环境http://112.48.19.225:8500

2.3 接口功能

分页查询企业完整信息，包含：

  • 企业基本工商信息
  • 经营信息（历年）
  • 主要技术（专利）
  • 主要产品
  • 荣誉资质
  • 投融资信息
  • 国际/国家/省级榜单排名
  • 知识产权统计信息

3. 请求说明

3.1 请求URL

GET http://112.48.19.225:8500/cms/tb-base-business-info/web/page

3.2 请求参数

参数名类型必填默认值说明
pageNumint否1当前页码，从1开始
pageSizeint否10每页显示条数，最大不超过100

3.3 请求示例

GET /cms/tb-base-business-info/web/page?pageNum=1&pageSize=10 HTTP/1.1
Host: 112.48.19.225:8500
Accept: application/json

10. 错误码说明

错误码说明处理建议
0请求成功正常处理数据
1001参数错误检查请求参数是否合法
1002分页参数超出范围调整pageNum或pageSize
2001数据不存在确认查询条件是否正确
